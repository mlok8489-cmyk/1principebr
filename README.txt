# 1principebr

Site inicial do 1principebr, com visual preto + roxo.

## Arquivos
- index.html
- style.css
- script.js

## Antes de publicar
No `index.html`, substitua os `href="#"` pelos seus links reais da Twitch, TikTok e YouTube.

No `style.css`, a variável `--purple` controla o roxo principal do site. Quando você me enviar o avatar principal, podemos pegar o HEX exato para deixar o site combinando com ele.
